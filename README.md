# Inclúyeme en tu Mundo A.C. — Sitio Web Institucional

Sitio web institucional desarrollado para la ONG **Inclúyeme en tu Mundo A.C.**, organización ubicada en Villahermosa, Tabasco, dedicada a brindar terapias personalizadas para niños y jóvenes con neurodivergencias como Autismo (TEA) y TDAH.

---

## Descripción

Proyecto de desarrollo web front-end completo, desde la planificación hasta la implementación. El sitio busca fortalecer la presencia digital de la organización, facilitar el acceso a información sobre sus servicios y establecer un canal de contacto directo con familias que requieren apoyo.

---

## Páginas

| Página | Descripción |
|--------|-------------|
| `index.html` | Página de inicio con carrusel, servicios destacados y CTA |
| `quienes-somos.html` | Historia, misión, visión y valores de la organización |
| `servicios.html` | Catálogo de terapias y servicios ofrecidos |
| `autismo.html` | Información educativa sobre el Trastorno del Espectro Autista |
| `tdah.html` | Información educativa sobre el TDAH |
| `blog.html` | Listado de artículos informativos |
| `blog-1.html` / `blog-2.html` / `blog-3.html` | Artículos individuales del blog |
| `donar.html` | Página de donaciones y apoyo a la organización |
| `contacto.html` | Formulario de contacto e información de ubicación |
| `que-hacemos.html` | Detalle de las actividades y programas de la ONG |

---

## Stack

| Capa | Tecnología |
|------|------------|
| Estructura | HTML5 |
| Estilos | CSS3 (archivo por página + global.css) |
| Interactividad | JavaScript vanilla (archivo por página + global.js) |
| Mapas | Google Maps embed |
| Íconos | SVG propios |

Sin frameworks ni dependencias externas. Todo desarrollado desde cero.

---

## Características

- Diseño responsive adaptado a móvil, tablet y escritorio
- Carrusel de imágenes en la página de inicio
- Secciones interactivas con animaciones en scroll
- Formulario de contacto con validación de campos
- Mapa de Google Maps integrado con la ubicación real de la organización
- Blog con artículos informativos sobre autismo y neurodivergencias
- Identidad visual consistente con la imagen institucional de la ONG
- Galería de alianzas y donantes
- Sección de donaciones

## Cómo visualizarlo

No requiere servidor ni instalación. Solo abre `index.html` directamente en tu navegador.

Para una mejor experiencia durante el desarrollo se recomienda usar la extensión **Live Server** en VS Code.
